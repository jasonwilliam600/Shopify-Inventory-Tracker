---
name: Manufacturer names in supplier inventory
description: Merchant expects named manufacturers on Heartland inventory, not raw prefixes or Default labels.
---

Show the vendor/manufacturer names for Heartland feed products in the main inventory view as well as supplier-specific views. Keep the manufacturer distinct from the wholesaler supplying the inventory.

**Why:** The merchant repeated this request after the grouped inventory view omitted the names already visible elsewhere.

**How to apply:** Preserve manufacturer labels when introducing new inventory views or detail screens. Use verified supplier-specific manufacturer codes from original SKUs; do not invent names for unknown or shared codes, change identifiers, or treat manufacturer recognition as a verified Shopify match.
